# iamcstevenson.github.io

Public pages for my personal tools, served by GitHub Pages at https://iamcstevenson.github.io/.

- `tubedash/`: home page, privacy policy and terms for Tubedash. Google requires these, on a domain I've verified in
  Google Search Console, to publish Tubedash's Google sign-in. Keep the privacy policy in step with what Tubedash does
  with YouTube data (its code is in the private tube-dash repository).

Plain HTML and one stylesheet; no build step (`.nojekyll`).
